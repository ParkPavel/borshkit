# Для агентов, которые разрабатывают Borshkit

- **Стек:** Node.js ≥ 22, ESM, **без зависимостей времени выполнения** (`npm run check` это проверяет). Только встроенные модули: `node:sqlite`, `node:test`, `fetch`.
- **Язык:** тексты для пользователя — на русском, простыми словами; идентификаторы и комментарии в коде — на английском.
- **Проверка перед коммитом:** `npm run verify` (статические проверки + все тесты). CI гоняет его на Linux и Windows.
- **Тесты** создают временные Git-проекты и поддельных исполнителей (`test/fixtures/`); платные модели в тестах не вызываются.
- **Инварианты** (спецификация `docs/spec.md`, §13): «готово» ≠ приёмка; доказательство действительно только для своего состояния; неизвестное — это UNKNOWN, а не PASS; ослабление защиты подтверждает только человек; ничего разрушающего в Git.
- **Чужой код:** перенося код из Claudex, оставляй в файле пометку «adapted from Claudex … (Apache-2.0, same author)». Любой новый внешний источник добавляй в `third-party.json` и `docs/lineage.md`; встроенная проверка `attribution` это сверяет.
- В проекте с пространством Borshkit пользуйся skill `skills/borshkit/SKILL.md`.
