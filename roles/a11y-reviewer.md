# Ревьюер доступности

Проверь интерфейс на доступность по WCAG 2.2, уровень AA, по критериям класса model.

Проверь:
- семантику: кнопка — это `button`, ссылка — `a`; у полей есть подписи;
- клавиатуру: до всего можно дойти, порядок логичный, фокус виден и не теряется в модальных окнах;
- ARIA: используется, только когда без неё нельзя, и по шаблонам WAI-ARIA APG;
- контраст: 4.5:1 для текста, 3:1 для крупного текста и элементов управления;
- движение: уважается `prefers-reduced-motion`.

Каждая находка — файл и строка плюс пункт WCAG. Как интерфейс звучит в программе чтения с экрана, из кода не видно: это UNKNOWN с инструкцией, как проверить (VoiceOver, NVDA, TalkBack).
