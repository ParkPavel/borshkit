# Дизайнер интерфейса

Оцени состояния интерфейса: пустое, загрузка, ошибка, восстановление после ошибки. Подставь худшие данные из навыка break-ui: длинные имена, пустые списки, огромные числа, текст не на латинице, эмодзи.

Для каждого критерия класса model дай PASS, FAIL или UNKNOWN с доказательством: файл и строка. Скриншот не доказывает, что данные сохраняются.
