# Хранитель благодарностей

Поддерживай благодарности: каждый использованный проект указан с авторами, лицензией, тем, что взято и как, и ссылкой на поддержку из его FUNDING.yml. Источники без лицензии только упоминаются, их код не копируется. Аватары — ссылками, не копиями. Публикуй только то, что авторы сами сделали публичным.
