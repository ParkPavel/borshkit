Текущая архитектура#

Borshkit — локальная CLI на Node.js 22+, без зависимостей времени выполнения. Это переносимый слой задач, контекста и доказательств для работы с кодом. Сам по себе он не заменяет ИИ-харнес и не гарантирует качество модели.

Слой Реализация Граница
Контракт core/contract.mjs, core/snapshot.mjs цель, paths, критерии, база и точное состояние
Контекст core/kb.mjs, core/roles.mjs, core/jobs.mjs JS/TS, Python, Go, Swift и Markdown; ограниченный пакет, обрезка не означает полноту
Исполнение core/jobs.mjs, core/adapters.mjs, core/process.mjs отдельная Git worktree для писателя; API пишет только в paths
Проверки core/accept.mjs PASS/FAIL/UNKNOWN и лог, привязанные к состоянию; сбой запуска — UNKNOWN
Решение core/accept.mjs, core/gitshell.mjs ответ модели не принимает задачу; ручные пункты, отдельные сборка и отправка
Передача задачи core/handoff.mjs, core/context-pack.mjs контракт и контекст с происхождением; импорт не переносит приёмку
Перенос проекта core/portable.mjs, core/integrations.mjs явные файлы и шаблон настроек; доказательства и доверие на новой машине проверяются заново

Уровни поддержки сред#

Среда Экспорт инструкций Запуск исполнителя Специальная интеграция
Claude Code CLAUDE.md адаптер CLI плагин, навык, команды и hooks
Codex AGENTS.md адаптер CLI инструкции и запуск; отдельный плагин не заявлен
Gemini GEMINI.md CLI и API инструкции и адаптеры
Copilot / Roo / Cline файлы правил нативный путь из VSIX Copilot LM API без инструментов; Roo start/cancel/events; Cline start, статус/отмена UNKNOWN/UNSUPPORTED
OpenAI-совместимый API не требуется API-адаптер зависит от схемы ответа и возможностей endpoint

Адаптеры тестируются поддельными программами и ответами API. Это проверяет протокол, а не качество живых моделей. VSIX опубликован в GitHub Release 0.13.0; в VS Code Marketplace расширение не опубликовано.

Передача и нативные среды#

core/handoff.mjs экспортирует и импортирует задачи по схеме 1; core/context-pack.mjs сохраняет происхождение и пропуски при сжатии. Импорт не переносит приёмку. Нативный путь описан в руководстве, включая отсутствие достоверной отмены Cline. Автоматическая запись ответа Copilot и автоматическая приёмка не выполняются.

Надёжность Git#

Читающие команды повторяются только после аварии процесса или временного отказа запуска. Записи, commit, merge и push автоматически не повторяются. Таймаут, отмена, отсутствие программы и ненулевой ответ — разные причины ошибки. stderr сохраняется в диагностике. Запрос остановки дерева ограничен по времени; при отказе Windows taskkill используется прямое завершение. ОС может отказать в завершении чужого процесса — программа сообщает сбой, а не обещает, что дерево исчезло.

Ревью получает diff только внутри paths и содержимое новых текстовых файлов. На diff выделено до 9000 символов, на объединённый контекст — 12000; diff идёт первым. Обрезка обозначается. Двоичные файлы и неподдерживаемые типы требуют отдельной проверки.
