Borshkit#

Иллюстрация рабочего цикла: задача, контекст и доказательства.

Задачи, переносимый контекст и доказательства результата для ИИ-разработки.

Опиши результат. Поручи работу агенту. Получи доказательства, привязанные к состоянию файлов, и понятный список того, что проверить самому.

Что работает сейчас#

CLI, плагин Claude Code и VSIX. Запуск Claude Code, Codex, Gemini и API-исполнителей; нативные API Copilot/Roo/Cline из VS Code с явными ограничениями. Передача задачи между средами и статическая карта JS/TS, Python, Go, Swift. Нативные возможности и границы.

Ответ «готово» не принимает задачу. Проверки, независимое ревью и решения человека сохраняются отдельно. Изменение файлов делает старые доказательства устаревшими.

PASS — проверка прошла; FAIL — проверка не прошла; UNKNOWN — доказательств нет. Живые испытания моделей и устройств ожидаются от пользователей.

Нужен ли платный ИИ?

Для задач и локальных проверок модель не нужна. Работа агента использует отдельно настроенную среду и её тариф.

Что переносится между средами?

Контракт, решения и ограниченный контекст с происхождением. История чата и доверенная приёмка не переносятся.

Credits / Источники

Borshkit — это борщ: собран из лучших ингредиентов, которые другие люди вырастили и открыто выложили.

Некоторые ингредиенты прошли термическую обработку дважды. Spec Kit сначала потушили в Claudex, потом ещё раз — уже как проверку спецификации, и только после этого он доварился в Borshkit. До стола всё дошло в лучшем виде: лицензии сохранены, авторы названы.

Ингредиент Что взято
Claudex ядро: контракт задачи, доказательства, сверка, адаптеры CLI
Ponytail (поддержать) «ленивый сеньор» — делать минимально и просто
emilkowalski/skills 14 навыков дизайн-инженерии и анимации
ECC (поддержать) 9 фронтенд-навыков, идея модулей
Spec Kit путь «намерение → спецификация → задачи → сверка» (через Claudex, дважды)
Superpowers (поддержать) отдельная копия для агента, тест до исправления (через Claudex)
Graphify (поддержать) происхождение связей в карте кода (идея, через Claudex)
prompt-agent оценка прошлых работ (идея, через Claudex)
HIGAgentSkills маршрутизация по Apple HIG (только ссылка)
Agent Reach маршруты сбора из интернета для исследователя
free-llm-api-resources подсказка при выборе бесплатных API (только ссылка)
