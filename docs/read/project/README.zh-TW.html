Borshkit#

工作流程示意圖：任務、情境與證據。

AI 程式開發的任務、可攜情境與可驗證成果。

說明預期成果，交給代理執行，再取得綁定確切檔案狀態的證據與人工驗收清單。

ru · en · de · ko · zh-TW · fr

開始使用#

0.13.0 · Node.js 22+ · Git

請安裝已驗證的 GitHub Release 壓縮檔。套件尚未發布至 npm 登錄庫。修改原始碼請用 git clone 和 npm link。

sh
npm install -g https://github.com/ParkPavel/borshkit/releases/download/0.13.0/borshkit.tgz
borshkit help

Quickstart · Guide · Commands · Website

目前支援#

提供 CLI、Claude Code 外掛與 VSIX，支援 Claude Code、Codex、Gemini、API 執行器，以及 VS Code 中的 Copilot、Roo、Cline 原生 API，並明確標示限制。提供任務交接及 JS/TS、Python、Go、Swift 靜態程式地圖。支援範圍與限制。

PASS：檢查通過。FAIL：檢查未通過。UNKNOWN：缺少證據。實際模型與裝置測試正等待使用者回饋。CLI 訊息和大部分指南為俄文，命令另有英文別名。

Architecture · Roadmap · 詳細資料與限制 · Context handoff

任務 情境 證據
目標、範圍與驗收條件 跨環境交接 綁定檔案狀態的檢查
需要付費 AI 模型嗎？

任務與本機檢查不需要模型。代理工作使用另外設定的環境及其費率。

交接包含什麼？

契約、決策與附帶來源的有限情境。不移轉聊天紀錄或受信任的驗收結果。

支持 Borshkit#

開源依靠人們的參與成長。協助支持開發時間，讓工具更易於使用。

Credits / Источники

Borshkit 就是一鍋羅宋湯：用別人親手種出、公開分享的最好食材煮成。

有些食材下鍋了兩次。Spec Kit 先在 Claudex 裡燉過一輪，又以規格檢查的身分再熬一次，最後才在 Borshkit 裡起鍋。端上桌時一切完好：授權都保留了，作者也都有署名。

食材 取用了什麼
Claudex 核心：任務契約、證據、收斂、CLI 轉接器
Ponytail（贊助） 「懶惰的資深工程師」——只做必要的事，保持簡單
emilkowalski/skills 14 個設計工程與動態效果技能
ECC（贊助） 9 個前端技能，以及模組化的想法
Spec Kit 「意圖 → 規格 → 任務 → 收斂」這條路徑（經由 Claudex，兩次）
Superpowers（贊助） 給代理的獨立副本、先寫測試再修正（經由 Claudex）
Graphify（贊助） 程式碼地圖中連結的來源出處（想法，經由 Claudex）
prompt-agent 為過去的工作評分（想法，經由 Claudex）
HIGAgentSkills 依 Apple HIG 分派（僅連結）
Agent Reach 研究員用的網路蒐集路徑
free-llm-api-resources 挑選免費 API 時的參考（僅連結）
