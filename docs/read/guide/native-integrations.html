Copilot, Roo и Cline: нативный запуск#

0.13.0 добавляет вызовы публичных API из VSIX Borshkit. Это отдельный путь запуска из VS Code; команды работа запустить и обычные CLI/API-исполнители остаются прежними. Для всех трёх сред по-прежнему доступен экспорт файлов инструкций.

Подготовить и запустить#

  1. Создай и заполни контракт задачи, например dark-mode.
  2. В терминале основного проекта выполни:
sh
borshkit интеграция prepare dark-mode --host roo

Вместо roo допустимы cline и copilot. Команда создаёт отдельную Git-копию и локальный запрос в .state/native пространства, проверяет исходящий пакет на приватность и возвращает file и cwd. Ничего не запускается автоматически. Один подготовленный запрос запускается не более одного раза; повтор требует finish и новой подготовки.

  1. Установи VSIX Borshkit и выбранное расширение. Открой возвращённый cwd как единственную папку VS Code. Без доверия workspace или при несовпадении папки запуск отклоняется.
  2. Вызови Borshkit: нативный запуск задачи, выбери файл запроса и подтверди запуск. Для Copilot выбери точную модель из реально доступных в аккаунте. VS Code отдельно запрашивает согласие на Language Model API.
  3. Состояние видно в канале вывода и рядом с запросом в .status.json. Ответ Copilot сохраняется в .answer.txt. Изменившийся после подготовки код требует нового запроса.
  4. После остановки всех нативных работ выполни в терминале основного проекта borshkit интеграция finish dark-mode и подтверди, что среда остановлена. Это освобождает копию для других писателей и не принимает задачу. До finish новый писатель Borshkit и новая подготовка блокируются.
  5. После работы используй обычные задача проверить, независимое ревью и задача итог. Ответ харнеса и событие completed не принимают задачу.

Полномочия и ограничения#

Среда Реальный вызов Отмена и статус
Copilot vscode.lm.selectChatModels({vendor:'copilot'}), model.sendRequest CancellationToken; поток текста без инструментов; ответ — предложение, файлы автоматически не записываются
Roo startNewTask({text,newTab:false}) cancelCurrentTask, getCurrentTaskStack, taskCompleted/taskAborted с точным ID; чужая задача не отменяется
Cline startNewTask(text) текущий публичный API не даёт ID/достоверного статуса/однозначной отмены: LAUNCHED_STATUS_UNKNOWN; остановка вручную в Cline

Возможное авторство Roo/Cline записывается с неизвестным семейством. Даже доверенный модельный PASS не доказывает независимость и остаётся пунктом для человека. Finish не стирает это авторство.

Borshkit не нажимает кнопки согласия Cline и не меняет настройки auto-approve Roo/Cline. Их инструменты и запросы разрешений контролирует сама среда. Отдельная Git-копия не является системным sandbox; настройки среды и доступ к остальным файлам нужно оценивать отдельно.

В строгом режиме нативный путь заблокирован: из API нельзя подтвердить политику данных выбранного аккаунта/модели. Используй уже проверенного CLI/API-исполнителя с утверждённой политикой. Перенастройка приватности или контракта после подготовки делает запрос устаревшим, как и изменение файлов.

Таймаут означает неизвестный итог, если среда не подтверждает остановку. Cline не получает вымышленный статус «отменено». Для Roo проверяется активный стек; при занятости запуск отказывается заменять чужую работу. При перезапуске VS Code локальная запись остаётся исторической, состояние нужно проверить в среде.

Официальные контракты API#

Сверены 22 октября 2026, код upstream не копируется:

  • VS Code Language Model API
  • Roo API, commit b867ec9 и события
  • Cline API, commit c441897

Живые расширения и аккаунты в этом выпуске не проверялись: владелец оставил эти испытания пользователям. Несовместимая версия или отсутствующая функция даёт отказ, а не автоматическое ослабление защиты.
