Подробности и ограничения — 0.13#

Команда, которую видно#

borshkit команда показывает модели, актуальность подключения, оценки ролей, назначенные пулы и известные ресурсы. borshkit команда план <задача> объясняет подбор и резервирует отдельное семейство для ревью. команда предложить сохраняет предложение; применение и запуск выполняются отдельно. Устаревшие данные блокируют применение. Бесплатность API проверяется в аккаунте; неизвестный остаток явно отмечается.

Новая роль design-prompter пишет задание для визуального дизайна. Модель выбирают по оценке конкретной роли, а не по названию бренда. Команды и форматы · Архитектура команды и следующие этапы · Аудит.

borshkit мастер сохраняет выбор среды, безопасности, конкретных моделей и ролей; --диалог работает в терминале, пошаговые команды — из приложения. Руководство. Совместимость проверяется отдельно от качества; предложение не применяется и не запускает работы.

Passkey-подтверждение настроек и критических вопросов с телефона реализовано после доверенного сопряжения. Добавлены assessment, общий бюджет/WIP, зависимости и checkpoints, явный monitor start/stop, Gemini CLI/API, локальный VSIX и перенос явных файлов с повторной проверкой.

В 0.13 доступны экспорт инструкций и нативный запуск из VSIX: Copilot возвращает текст без инструментов, Roo использует ID/события/отмену, Cline предоставляет только запуск с неизвестным статусом. Строгая приватность блокирует нативный путь. Возможности, установка и ограничения. Автопилот по умолчанию выключен.

Работа команды, безопасность и ограничения · Контроль модернизации. Локальные тесты не заменяют проверку реальной модели, браузера телефона, VS Code и CI точной версии.

Главная идея#

Модель пишет «готово». Это ещё не приёмка:

  • каждое доказательство привязано к точному состоянию файлов;
  • что можно проверить автоматически, проверяется автоматически;
  • что нельзя, становится короткой инструкцией для тебя;
  • что не проверено, так и называется: не проверено.

Установка#

Нужны Node.js 22+ и Git. Внешних зависимостей нет.

Плагин Claude Code:

команда
/plugin marketplace add ParkPavel/borshkit
/plugin install borshkit@borshkit

Плагин добавляет навык, slash-команды и защитные hooks Claude Code. Он не устанавливает глобальные команды в PATH. Для borshkit и borsch в терминале отдельно установи CLI, как показано ниже.

Команда в терминале:

sh
git clone https://github.com/ParkPavel/borshkit.git
cd borshkit && npm link        # появятся команды borshkit и borsch

Или одной командой из последнего релиза, без клона:

sh
npm install -g https://github.com/ParkPavel/borshkit/releases/latest/download/borshkit.tgz

Пакет пока не опубликован в реестре npm; команда выше устанавливает архив GitHub напрямую.

Первая задача#

sh
cd мой-проект
borshkit начать                                   # папка borshkit/ в корне, скрыта от истории проекта
borshkit исполнитель добавить codex
borshkit исполнитель добавить claude              # Claude Code по подписке; подтверждаешь в терминале
borshkit задача новая dark-mode --цель "Тёмная тема в настройках"
borshkit работа запустить dark-mode --роль architect --исполнитель claude    # предложит цели и критерии
# Сначала проверь architect-proposal.json и перенеси согласованные goals, criteria, checks в contract.json.
borshkit работа запустить dark-mode --роль implementer --исполнитель claude  # пишет код в отдельной копии
borshkit задача проверить dark-mode                    # тесты, сборка, линтер
borshkit работа запустить dark-mode --роль reviewer --исполнитель codex      # ревью от другой семьи моделей
borshkit задача итог dark-mode                         # лист приёмки: что доказано, что ждёт тебя
borshkit задача подтвердить dark-mode C3 да "видел тёмную тему после перезапуска"
borshkit собрать dark-mode && borshkit отправить       # в основную версию и на GitHub — только с твоего «да»

Подробно, с объяснением каждого шага: быстрый старт. Все команды есть и по-английски (init, task new, job run …) — справочник.

Как это работает#

Текущее устройство и уровни поддержки сред описаны в архитектуре. Подробный рабочий цикл — в руководстве.

Что умеет#

Область Что это даёт
Приёмка по целям критерии auto / model / manual, лист приёмки, цели доверия к моделям, подтверждённые измерением
Пространство папка borshkit/ = хранилище Obsidian со своей историей; правило .gitignore ставится и проверяется само
Исполнители Claude Code, Codex (с GPT Image), любые OpenAI-совместимые API, свои программы; пулы с переключением
21 роль архитектор, разработчик, ревьюеры, тестировщик, исследователь, дизайнеры, автор дизайн-промпта, оформитель README…
Автопилот рутинные вопросы решаются ответом по умолчанию через минуту; критические — стоп с отчётом и передачей контекста
Диспетчерская кому ушло, кто работает, что ждёт тебя: в терминале, в STATUS.md и в строке статуса Claude Code
Исследования источники хранятся копиями; проверка citations сверяет каждую цитату дословно
Приватность три режима; задание для агента проверяется на ключи и персональные данные до отправки; настройки меняются только через предложения
Git для новичка «что изменилось», «кто это менял», «верни как было» — простыми словами и без разрушающих команд
Благодарности проверки attribution и readme-assets, полный список контрибьюторов всех источников

Фронтенд, дизайн и iOS#

В Borshkit есть роли для интерфейсов, и каждая получает только свои навыки:

Роль Что делает Навыки и первоисточники
ui-engineer делает интерфейс: все состояния, анимация, клавиатура Emil Kowalski, ECC; Vercel Web Interface Guidelines, shadcn/ui, Radix, React Aria, WCAG
ios-designer проверяет интерфейс iPhone и iPad apple-design, Liquid Glass, SwiftUI; Apple HIG, SF Symbols
motion-reviewer строго проверяет анимации review-animations, animation-vocabulary, motion-foundations
a11y-reviewer проверяет доступность по WCAG 2.2 AA ECC accessibility, frontend-a11y; WAI-ARIA APG, axe-core
designer ломает интерфейс худшими данными break-ui

Библиотека: 3 пакета навыков (25 навыков) и 63 проверенные ссылки — компоненты, анимация, дизайн-системы, доступность, иконки, шрифты, инструменты качества. В терминале: borshkit навыки и borshkit библиотека.

Рецепт#

Borshkit — это борщ: собран из лучших ингредиентов, которые другие люди вырастили и открыто выложили.

Некоторые ингредиенты прошли термическую обработку дважды. Spec Kit сначала потушили в Claudex, потом ещё раз — уже как проверку спецификации, и только после этого он доварился в Borshkit. До стола всё дошло в лучшем виде: лицензии сохранены, авторы названы.

Ингредиент Что взято
Claudex ядро: контракт задачи, доказательства, сверка, адаптеры CLI
Ponytail (поддержать) «ленивый сеньор» — делать минимально и просто
emilkowalski/skills 14 навыков дизайн-инженерии и анимации
ECC (поддержать) 9 фронтенд-навыков, идея модулей
Spec Kit путь «намерение → спецификация → задачи → сверка» (через Claudex, дважды)
Superpowers (поддержать) отдельная копия для агента, тест до исправления (через Claudex)
Graphify (поддержать) происхождение связей в карте кода (идея, через Claudex)
prompt-agent оценка прошлых работ (идея, через Claudex)
HIGAgentSkills маршрутизация по Apple HIG (только ссылка)
Agent Reach маршруты сбора из интернета для исследователя
free-llm-api-resources подсказка при выборе бесплатных API (только ссылка)

Полный рецепт с версиями и лицензиями — docs/ingredients.md. Все контрибьюторы этих проектов, 1262 записи — CONTRIBUTORS-REFERENCES.md. Спасибо каждому!

Границы#

  • Borshkit проверяет задание, которое сам отправляет агенту. Что Claude Code или Codex потом читают из файлов копии проекта, он не видит: игнорируемых файлов (.env) в копии нет, а остальные доступны агенту целиком.
  • Проверки задач (тесты, сборка) запускаются с твоим окружением: тестам бывают нужны ключи. Фильтр окружения действует только на исполнителей.
  • Карта знаний понимает связи кода JS/TS и Markdown. Файлы Swift, Python, Go и других языков в неё пока не попадают; на приёмку это не влияет.
  • Адаптеры Claude Code, Codex и Gemini проверены на поддельных программах с тем же форматом событий. Флаги установленного Claude Code сверены. Живых запусков с настоящими моделями в CI нет.
  • Картинки через Codex (GPT Image) не проверены: это покажет borshkit исполнитель проверить codex на твоей подписке.
  • Видит ли граф Obsidian связи из свойств заметок, не проверено. Поэтому связи продублированы обычными ссылками в тексте.
  • Сообщения Borshkit пока только на русском; команды и флаги — на русском и английском.
  • node:sqlite в Node 22 пока экспериментальный.
  • Поиск ключей и персональных данных по шаблонам ловит не всё.
