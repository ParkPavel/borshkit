Формат задачи (contract.json)#

Задача живёт в borshkit/tasks/<имя>/contract.json. Её создаёт borshkit задача новая, а цели и критерии дописываешь ты или роль architect. Готовый пример — examples/contract.json.

Поля#

Поле Обязательно Что это
schemaVersion да всегда 2
taskId да имя задачи: латиница, цифры, - и _
kind да feature, bug, maintenance или research
goal да общая цель одной фразой
nonGoals да чего задача не делает (список, можно пустой)
decisions да уже принятые решения, чтобы агент их не пересматривал
base да исходный снимок; Borshkit заполняет сам
paths да какие файлы задача может менять; "." — весь проект
goals да цели: { "id", "text", "criteria": ["C1", …] }
criteria да критерии: { "id", "text", "class", "tag"?, "manual"? }
checks да проверки (ниже); могут вести только к критериям auto
materials нет номера материалов для исследования: ["m-0123456789ab"]
acceptance.policy да mixed (по умолчанию), auto или manual — см. Приёмка

Критерий#

json
{ "id": "C2", "text": "Переключатель подписан и доступен с клавиатуры", "class": "model", "tag": "ui-a11y" }
  • class — auto, model или manual.
  • tag — метка для цели доверия к модели (латиница, цифры, -).
  • manual — для ручной проверки: steps (шаги), expect (что должно быть видно), where (где смотреть).
json
{ "id": "C3", "text": "После перезапуска тема остаётся тёмной", "class": "manual",
  "manual": { "steps": ["Включи тёмную тему", "Перезапусти приложение"], "expect": "Тема тёмная", "where": "Тестовое хранилище" } }

Проверка-команда#

json
{ "id": "test", "command": "npm", "args": ["test"], "criteria": ["C1"], "timeoutMs": 120000 }

Команда запускается без оболочки, аргументы — списком. timeoutMs — до 15 минут (900000). Для пишущих ролей проверка идёт в копии задачи.

Встроенные проверки#

builtin Поля Что проверяет
citations report (путь к отчёту), minCitations цитаты дословно есть в материалах — Исследования
attribution manifest (по умолчанию third-party.json), readme каждый источник указан с лицензией и ссылкой; без лицензии — ничего не скопировано
readme-assets readme, maxBytes (по умолчанию 1 МБ) картинки на месте, с alt-текстом, не тяжелее лимита; локальные ссылки ведут к файлам
json
{ "id": "cites", "builtin": "citations", "report": "research/report.md", "minCitations": 3, "criteria": ["C4"] }

Что подскажет задача анализ#

Контракт может быть правильным по форме, но обещать то, чего ничто не покажет. borshkit задача анализ <имя> предупредит, например:

  • критерий размытый: «быстро», «удобно», «корректно», «работает» — и без чисел;
  • у критерия auto нет проверки;
  • у ручного критерия нет шагов;
  • критерий не относится ни к одной цели или повторяет другой;
  • остались заглушки TODO, TBD или ???;
  • исследование без проверки citations или без материалов;
  • сколько критериев останется за тобой (слепая зона).

Предупреждения ничего не блокируют. Они показывают слепую зону до начала работы.
