Проверка модернизации — 20 октября 2026#

Исходное состояние#

GitHub проверен заново: main 621d58aae2c60ed1064fd19bc54fd1a16497471a, PR #14 открыт как draft, head 79c89dda7fb54214b83641917b6dfd02465feb76. Изменения PR перенесены в отдельную ветку с исправлениями. .state/save.lock, корневые настройки, START-HERE и журнал удалены из результата как локальные данные.

В доступной истории веток не обнаружен docs/index.html из прежнего чата. Сайт создан в текущей работе. GitHub Pages уже был настроен на main, /docs, HTTPS. Сайт — статические HTML/CSS/JS, без сборщика и внешних библиотек; .nojekyll отключает обработку Jekyll.

Проверки кода#

Регрессии покрывают выбор базы и рабочей копии; временный сбой читающего Git; отсутствие повторов commit/merge/push; stderr; таймаут и отмену; отказ и зависание Windows taskkill; signed/unsigned NTSTATUS и обычный POSIX exit 5; отказ распознавания Git-проекта при инфраструктурном сбое; scoped diff, содержимое новых файлов и обозначение обрезки; ошибку diff; различие UNKNOWN при отказе запуска и FAIL при ненулевом результате проверки.

Локальный npm run verify: 168 тестов, 167 прошли, один Windows-специфичный тест пропущен на Linux; ошибок нет. Команда запускает статические проверки и все тесты. Workflow CI выполняет эту команду на Ubuntu, Windows и macOS с Node.js 22. Итог удалённого CI нужно смотреть для точного SHA в PR, а не переносить с предыдущей версии.

Проверка сайта в браузере#

Локальный Chromium проверен через Playwright на размерах 1440×1000, 390×844 и 320×800. Проверены оба режима архитектуры, выбор слоёв, FAQ, наличие ссылок, отсутствие горизонтального переполнения и ошибок JavaScript. Отдельно проверены клавиатурная ссылка «К содержимому» и prefers-reduced-motion. На 320 px первоначально переполнялся заголовок; после исправления повторный прогон прошёл.

Снимки просмотрены при проверке:

  • Настольный первый экран
  • Мобильный первый экран
  • Целевая архитектура на настольном экране
  • Целевая архитектура на мобильном экране

Облачный Browser Use не смог подключиться к локальному preview (ERR_SOCKS_CONNECTION_FAILED); его снимки ошибки не считаются проверкой интерфейса. Локальный Chromium реально загрузил страницу. После публикации облачный браузер успешно открыл публичный сайт на 1440×1000 и 390×844 и проверил карту, FAQ, навигацию и копирование установки без ошибок JavaScript. Скриншоты не являются тестом на физических устройствах, Safari или экранном дикторе.

Дополнительная регрессия после слияния#

Повторный CI на main выявил неустойчивый CLI-тест. Обнаружен воспроизводимый дефект формирования контекста: полностью цифровой короткий Git ID в заголовке diff распознавался фильтром как телефон. Исправление добавляет к сгенерированному ID префикс git:; фильтры содержимого не ослабляются. Новый тест сначала падает на прежнем коде, затем проходит и отдельно подтверждает блокирование настоящего телефона в новом файле. Интеграционный тест создаёт настоящий Git-коммит с цифровым префиксом и проверяет запуск ревьюера. CLI-тест теперь сохраняет stdout/stderr в сообщении об ошибке.

Реальные ограничения#

Логи проблемной Windows-машины отсутствуют. Git Bash, антивирус, AnyDesk и нехватка памяти остаются гипотезами. Регрессии проверяют поведение при сбоях, а не устанавливают причину прежнего инцидента.

Живые платные модели не вызываются тестами. Качество моделей, работа на физических устройствах и нативные адаптеры Copilot/Roo/Cline не подтверждаются этим прогоном. Полный перенос сеанса и универсальное сжатие контекста — план. Пакет npm не опубликован; этот выпуск не создаёт новый GitHub Release.
