Статус пяти направлений — 0.13.1#

Пул модернизации реализован в исходниках и покрыт автоматическими тестами. По решению владельца от 22 октября 2026 живые проверки моделей и физических устройств ждут обратной связи пользователей и не являются условием этого выпуска. Это не объявление таких проверок успешными.

Направление Реализовано Проверено / граница
Единый пакет передачи задачи передача export/import, схема 1, контракт, состояние, решения, evidence references и неизвестное round-trip, отказ при порче и конфликте; приёмка и настройки не переносятся; новая задача начинается с состояния получателя
Сжатие с происхождением extractive-priority-v1, приоритеты, дедупликация, SHA источников/фрагментов, manifest пропусков, предел 512–120000 символов детерминированные тесты; важный фрагмент сохраняется там, где простая обрезка его теряет; качество живой модели не заявлено
Нативные интеграции VS Code Language Model API для Copilot; публичные API Roo и Cline; отдельная Git-копия и запрос с контролем состояния тесты контрактов API, отмены, таймаута и корреляции событий; строгая приватность блокирует неподтверждённый нативный путь; Cline API не даёт достоверных статуса и отмены — возвращается UNKNOWN/UNSUPPORTED
Карта кода шире JS/TS Python, Go и Swift, локальные imports/exports и связи тестов статический лексический разбор; динамические, внешние и неразрешённые импорты обозначаются явно; не замена компилятору
Проверка моделей и устройств отдельный opt-in live-check, формат отчёта, сценарии пользовательской проверки NOT_RUN до реального запуска; живые аккаунты и устройства ожидаются от пользователей

В 0.13.1 добавлены диагностика процессов, достоверные UNKNOWN/BLOCKED и документация внутри сайта. Границы выпуска.

Следующие итерации#

В исходниках после 0.13.1 реализованы работа в текущем харнесе и терминальное меню, согласование caller env и регистра переменных Windows, запрос остановки и наблюдение ресурсов. Архив 0.13.1 их не содержит. Единый расширенный профиль запуска, полное владение деревом ОС, лимиты CPU/RAM и контроль внешних MCP остаются следующими этапами. Решения и границы.

Это развитие после текущего пула, а не обещание готовых функций: более глубокий семантический анализ языков, новые публичные API отмены/статуса Cline, пользовательские испытания конкретных моделей и устройств. Активную историю чата LLM пакет задачи не клонирует.
