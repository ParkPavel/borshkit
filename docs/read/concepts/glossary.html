Словарь#

Одно слово — одно значение. Если в тексте Borshkit встречается слово из этого списка, оно значит именно это.

Слово Что значит
Пространство папка borshkit/ в корне проекта. В ней настройки, задачи, знания и журнал. У неё своя локальная история Git, а история проекта её не видит. → Пространство
Задача одна цель, которую надо довести до приёмки. Описана в файле contract.json. → Формат задачи
Цель что должно получиться, словами человека. Цель достигнута, когда выполнены все её критерии.
Критерий одно проверяемое утверждение о результате. Бывает трёх классов: auto, model, manual. → Приёмка
Проверка команда (тесты, сборка, линтер) или встроенная проверка Borshkit. Её результат — доказательство.
Доказательство запись «проверка X дала PASS на состоянии Y». Действует, только пока состояние не изменилось. → Доказательства
Состояние точный слепок файлов проекта: коммит и хеши всех файлов, включая несохранённые правки.
Устарело (STALE) доказательство снято с другого состояния. Его нельзя использовать, проверку надо повторить.
Лист приёмки файл acceptance.md задачи: что доказано, что нужно исправить, что посмотреть тебе самому.
Не проверено (UNKNOWN) честный ответ, когда доказательства нет. Это не PASS.
Исполнитель тот, кто делает работу: Claude Code, Codex, API с моделью или своя программа. → Исполнители
Пул упорядоченный список исполнителей. Если первый упёрся в лимит, работа переходит ко второму.
Роль что поручено исполнителю: архитектор, разработчик, ревьюер… Роль — это файл с инструкцией, а не отдельная программа. → Роли и навыки
Навык текст с опытом из другого проекта (например, правила анимации Emil Kowalski). Роль получает только свои навыки.
Пакет набор навыков из одного источника, с его лицензией и зафиксированной версией. Лежит в packs/.
Работа один запуск роли у исполнителя. У каждой работы есть номер, статус и журнал.
Автопилот режим, в котором рутинные вопросы через минуту получают ответ по умолчанию. Критические вопросы всё равно ждут тебя.
Материал сохранённая копия источника для исследования: файл, страница, текст. Цитировать можно только материалы. → Исследования
Знания заметки о проекте со связями [[…]] и SQL-индекс поверх них. → База знаний
