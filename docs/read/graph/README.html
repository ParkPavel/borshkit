Граф документации#

Эту страницу Borshkit написал сам: собрал свою базу знаний по этому репозиторию и выгрузил её. Команда — node scripts/docs-graph.mjs.

Всего в графе: модулей 58, тестов 33, документов 110, связей 1690.

  • borshkit.sql — весь граф одним SQL-скриптом. Загрузить: sqlite3 graph.db < borshkit.sql, потом спрашивать, например, SELECT * FROM undocumented_modules;.
  • Ниже — карта документов: стрелка значит «ссылается на». GitHub рисует её сам (Mermaid).
