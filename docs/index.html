ПЕРВАЯ ЗАДАЧА

Меньше догадок.
Больше опоры.

Нужны Node.js 22+ и Git. Работай в текущем Claude/Codex; дополнительная модель необязательна. Промежуточный выпуск: стабильная версия 0.13.1 доступна в релизах. Сообщения CLI — на русском; у команд есть английские имена.

Полный путь до приёмки
01

Установи команду

npm install -g https://github.com/ParkPavel/borshkit/releases/download/0.14.0/borshkit.tgz
borshkit помощь

Кнопка копирует команды целиком; длинный блок можно прокрутить. Готовый архив GitHub Release, без клонирования. В реестр npm пакет пока не опубликован. Другие способы установки и проверка происхождения.

02

В своём проекте

borshkit

Запускай из папки своего проекта. Меню предложит создать пространство и задачу. Цель вводится обычными словами; техническое имя меню создаёт автоматически.

03

Опиши, поручай, проверяй

Согласуй цель и критерии с текущим Claude/Codex. Работай его инструментами, затем запусти проверки. Дополнительного исполнителя подключай только при необходимости; независимое модельное ревью требует другого семейства.

ПОЧЕМУ ЭТО ВАЖНО

«Работало вчера» —
не доказательство сегодня.

Файлы изменились?

Старые проверки и подтверждения могут устареть. Результат относится к тому состоянию, на котором его получили.

Тест не запустился?

Это UNKNOWN. Сбой инструмента не доказывает дефект кода и не превращается в успешную проверку.

Нужен взгляд человека?

То, что нельзя доказать автоматически, остаётся понятным ручным пунктом. Решение видно в листе приёмки.

БЕЗ МАГИИ

Частые вопросы

Я новичок. С чего начать?

Установи команду и пройди quickstart на небольшой задаче. Сначала сформулируй, что должно измениться и как ты это проверишь. Borshkit поможет отделить сделанное от неизвестного.

Это ещё один ИИ-агент?

Это рабочий слой вокруг агентов: задачи, роли, ограниченный контекст, проверки и приёмка. Для генерации кода нужен отдельный исполнитель.

Какие среды поддерживаются?

Claude Code имеет плагин. Для Claude Code, Codex, Gemini и совместимых API есть адаптеры запуска. В VSIX есть нативный Copilot Language Model API и публичные API Roo/Cline. Copilot возвращает текст без автоматической записи файлов. У Cline достоверные отмена и статус недоступны. Строгая приватность блокирует нативный путь; живые проверки ждём от пользователей. Возможности и ограничения.

Можно передать задачу в другой чат?

Да. Единый пакет передаёт контракт, решения, ограниченный контекст с происхождением и исторические ссылки на доказательства. Импорт создаёт непроверенную задачу: приёмка и активная история чата не переносятся. Как передавать контекст

Код и ключи остаются локально?

Пространство локальное. Задание и выбранный контекст получает настроенный исполнитель. Borshkit фильтрует исходящий пакет, но шаблонный поиск не находит все секреты; CLI-агент может читать доступные файлы проекта. Границы приватности

Бесплатно? Есть пакет в npm?

Borshkit открыт по Apache-2.0. Ядро не требует платной подписки, но услуги исполнителя оплачиваются отдельно. В npm пакет не опубликован: используй клон и npm link или архив GitHub Release.

Как помочь проекту?

Сообщи об ошибке, предложи исправление или поддержи автора. Проверяемый сценарий ценнее догадки о причине сбоя.
