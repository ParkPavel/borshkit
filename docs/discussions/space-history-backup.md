# Черновик обсуждения: резервная копия истории пространства

> Черновик для GitHub Discussions (решение D20). Опубликовать, когда в настройках репозитория будут включены Discussions.

**Контекст.** У каждого проекта есть папка пространства `borshkit/` со своей локальной историей Git: настройки, знания, задачи, листы приёмки. Она скрыта от истории проекта и никогда не покидает компьютер. Если диск потерян, пропадёт и она.

**Вопрос.** Нужна ли резервная копия и какая?

| Вариант | Плюсы | Минусы |
|---|---|---|
| Ничего (сейчас так) | ничего не уходит с машины | потеря диска = потеря знаний и решений |
| Приватный удалённый репозиторий | история и восстановление одной командой | данные пространства уходят на сервер; нужно учесть режим приватности |
| Папка облачного диска (копия `.git` пространства) | просто, без серверов Git | синхронизация может испортить репозиторий, если он открыт на двух машинах |
| Экспорт архива по команде | полный контроль | легко забыть |

**Что важно учесть:** в строгом режиме приватности ничего не должно уходить наружу без явного согласия; в настройках нет ключей, но в знаниях и листах приёмки может быть описание приватного кода.
