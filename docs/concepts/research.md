# Исследования: источники и цитаты

**Коротко:** любой источник сначала сохраняется как материал задачи. Отчёт ссылается только на материалы и цитирует их дословно. Встроенная проверка `citations` сверяет каждую цитату с сохранённой копией.

## Добавить источник

```sh
borshkit материал добавить отчёт.pdf                     # файл
borshkit материал добавить --url https://example.com     # страница как есть
borshkit материал добавить --url https://example.com --через jina   # страница, очищенная Jina Reader
borshkit материал добавить --текст "заметка с интервью" --название "Интервью 1"
borshkit материал добавить --команда "yt-dlp --dump-json https://…" --url https://…   # вывод инструмента
```

Материал хранится копией. Его номер (`m-0123456789ab`) вычисляется из адреса и содержимого, поэтому другой текст — это другой материал. Страницу из интернета можно перечитать: `borshkit материал обновить <id>` сохранит новую версию рядом со старой и покажет, изменилась ли она.

`--команда` — это способ подключить инструменты из маршрутов [Agent Reach](https://github.com/panniantong/agent-reach) (yt-dlp, gh и другие). Сам Agent Reach в Borshkit не встроен; `borshkit доктор` покажет, установлен ли он.

В строгом режиме приватности запрос в интернет требует `--да`.

## Как цитировать

В отчёте:

```
Скорость выросла вдвое (источник: m-0123456789ab, «в два раза быстрее»).
```

Материал нужно объявить в контракте задачи, в поле `materials`.

## Что проверяет `citations`

- каждый источник объявлен в задаче;
- сохранённая копия цела;
- каждая цитата найдена в источнике слово в слово (пробелы и регистр не важны);
- в отчёте нет адресов, которые не пришли через `материал добавить`: источник, прочитанный в обход Borshkit, не засчитывается.

Чего проверка **не** решает: следует ли утверждение из цитаты. Это критерий класса `model` или `manual`.

Если формат не читается как текст (например, картинка), проверка отвечает «не проверено» и просит сверить цитату тебя.
