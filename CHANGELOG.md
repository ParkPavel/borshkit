# Изменения

## 0.10.1 — 2026-10-06

- **Плагин сам даёт команды.** Команды `borshkit` и `borsch` из папки `bin/` плагина теперь есть в терминале Claude Code, без отдельного `npm link`. Раньше навык просил агента запускать `borshkit`, а сама команда была только у тех, кто ставил CLI вручную.
- Тесты больше не спотыкаются о фоновую сборку мусора Git при удалении временных папок.
- В README — Telegram-канал автора.

## 0.10.0 — 2026-10-06

- **Фронтенд, дизайн и iOS.** Четыре новые роли: `ui-engineer`, `ios-designer`, `motion-reviewer`, `a11y-reviewer`. Роль `designer` теперь ломает интерфейс худшими данными.
- **Пакеты навыков.** Навыки Emil Kowalski (14) и фронтенд-навыки ECC (9) скопированы с лицензиями и зафиксированными версиями. Роль получает только свои навыки; другие можно добавить к работе флагом `--навыки пакет/навык`. Новая команда `borshkit навыки`.
- **Библиотека.** 63 проверенные ссылки: компоненты, анимация, дизайн-системы, доступность, иконки, шрифты, инструменты качества. Роли интерфейса получают свою часть списка. Команда `borshkit библиотека [категория]`.
- **Документация как база знаний.** Документация переписана простыми словами и устроена как заметки Borshkit. Её читает GitHub, Obsidian рисует граф, а Borshkit строит SQL. Документы проекта с frontmatter Borshkit дают типизированные связи. Граф документации Borshkit собирает сам (`docs/graph/`).
- **SQL-выгрузка графа:** `borshkit знания экспорт --sql граф.sql`.
- **README на шести языках:** русском, английском, немецком, корейском, традиционном китайском и французском. Анимированные схемы на каждом языке, с тёмной темой и уважением к настройке «меньше движения».
- **Рецепт.** `docs/ingredients.md` вместо `docs/lineage.md`: все ингредиенты, включая пришедшие через Claudex (Spec Kit, Superpowers, Graphify, prompt-agent, HIGAgentSkills). Список контрибьюторов дополнен до 1262 записей.

## 0.9.0 — 2026-10-06

Весь стек из спецификации собран и проверен тестами (66+) на Linux и Windows.

- **Пространство:** папка `borshkit/` в корне проекта — хранилище Obsidian со своей локальной историей Git; правило игнорирования добавляется и проверяется автоматически; работа в папках без Git.
- **Приёмка по целям:** цели, критерии `auto` / `model` / `manual`, доказательства, привязанные к точному состоянию; лист приёмки для человека; цели доверия к моделям, подтверждаемые измерением.
- **Материалы и исследования:** копии источников по содержимому, проверка цитат, Jina Reader и инструменты Agent Reach как источники.
- **Приватность:** режимы «умеренный», «строгий», «эксперимент»; настройки через предложения; доверенный агент; правка в обход останавливает записи; журнал ключей эксперимента.
- **Исполнители и работы:** Claude Code, Codex, OpenAI-совместимые API, свои команды; проверка возможностей; пулы с переключением при лимитах и молчании; 13 ролей; линза «ленивый сеньор» (Ponytail); отдельная копия проекта для пишущих ролей.
- **Автопилот и диспетчерская:** рутинные вопросы с ответом по умолчанию, критическая остановка с отчётом и передачей контекста; `STATUS.md`, `status.html`, строка статуса.
- **База знаний:** заметки с типизированными `[[связями]]`, SQL-индекс только на чтение, срез контекста, уроки с контролем устаревания, экспорт для GitHub.
- **Атрибуция:** проверки `attribution` и `readme-assets`, полный список контрибьюторов референс-проектов (`CONTRIBUTORS-REFERENCES.md`).
- **Git для новичка:** история, изменения, авторство, возврат с копией, сборка принятой задачи, отправка без перезаписи чужого.
- **Плагин Claude Code:** маркетплейс, hooks (только в проектах с пространством), skill; `AGENTS.md` для Codex и других агентов.
- **Оценка:** ложные PASS по скрытым проверкам, вмешательства, расход; измерение доверия к моделям.
