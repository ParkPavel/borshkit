# С чего начать

Это **пространство Borshkit** — рабочий стол твоего проекта. Здесь лежит всё, что Borshkit знает о проекте и о твоих задачах. Папку можно открыть в Obsidian как хранилище.

| Где | Что там |
|---|---|
| `settings/` | настройки; понятная версия — [[settings]] |
| `tasks/` | задачи: что нужно сделать, как проверяется, что уже проверено |
| `knowledge/` | знания о проекте: понятия, решения, уроки |
| `journal.md` | что происходило, простыми словами |
| `STATUS.md` | диспетчерская: кому ушла работа и кто сейчас работает |

Карта проекта появится после `borshkit знания собрать`: [[knowledge/_generated/index.md|карта проекта]].

## Две истории

- **История проекта** — твой код и документы. Её можно отправить на GitHub, но только после твоего «да».
- **История пространства** — эта папка: настройки, знания, проверки. Она **никогда не покидает компьютер**. Git проекта её не видит: папка `borshkit/` добавлена в список игнорируемых.

Git — это «машина времени» для файлов: каждое сохранение — точка, к которой можно вернуться. Borshkit делает такие точки сам, когда происходит что-то важное, например принята задача.

## Что дальше

1. `borshkit исполнитель добавить claude` — кто будет работать (или `codex`).
2. `borshkit задача новая <имя> --цель "что должно получиться"` — создать задачу.
3. `borshkit задача анализ <имя>` — проверить, понятно ли описаны критерии.
4. `borshkit работа запустить <имя> --роль implementer --исполнитель claude` — поручить работу.
5. `borshkit задача итог <имя>` — узнать, что доказано и что ждёт тебя.

Подробно, с объяснением каждого шага: https://github.com/ParkPavel/borshkit/blob/main/docs/guide/quickstart.md
