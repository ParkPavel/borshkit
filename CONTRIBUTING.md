# Как помочь Borshkit

Спасибо, что хочешь помочь! Несколько правил, чтобы изменения проходили легко.

## Перед изменением

- Прочитай [AGENTS.md](AGENTS.md) — там стек и инварианты (они же для людей).
- Большие идеи сначала обсуди в issue: проект намеренно маленький, и каждый новый слой должен доказать пользу (спецификация, §14–§17).

## Код

- Node.js 22+, ESM, **без зависимостей времени выполнения**.
- Тексты для пользователя — на русском, простыми словами; код и комментарии — на английском.
- Ничего разрушающего в Git, никаких автоматических «принято» без доказательств, неизвестное — это UNKNOWN.

## Проверка

```sh
npm run verify
```

Новое поведение — с тестом: временные Git-проекты и поддельные исполнители лежат в `test/helpers.mjs` и `test/fixtures/`. Платные модели в тестах не вызываются.

## Чужой код и благодарности

Если переносишь чужой код или тексты, укажи источник в файле, добавь его в [`third-party.json`](third-party.json) и [`docs/lineage.md`](docs/lineage.md). Проекты без лицензии можно только упоминать. `borshkit атрибуция проверить --readme docs/lineage.md` должна проходить.
